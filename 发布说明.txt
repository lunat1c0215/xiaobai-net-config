小白盒子配网工具 2.0
====================

一、怎么运行
  1. 解压整个文件夹（不要只拿 exe）。
  2. 双击「启动小白配网工具.vbs」。
  3. 首次打开会自动识别打印机队列，底部会显示「Word 里请选：...」。
  4. 随时点面板上的「使用说明」按钮，打开完整图文说明。

二、换网络（配网）
  1. 盒子通电，靠近电脑（蓝牙 10 米内）。
  2. 点「扫描盒子」。如果电脑蓝牙是关的，会先弹窗问你：
     点「是」→ 程序自动打开蓝牙后继续扫描；
     点「否」→ 跳到 Windows 蓝牙设置，你自己打开。
  3. 等它列出盒子能搜到的 Wi-Fi。
  4. 选中目标 Wi-Fi；记住过的会自动填密码。
  5. 点「配网 + 同步打印机」。
  6. 等进度条走完。盒子联网且端口改好后，直接回 Word 点打印。

  用手机热点时：盒子只支持 2.4GHz，不能连 5GHz。
    安卓：热点设置 → AP 频段 → 2.4GHz
    iPhone：个人热点 → 打开「最大兼容性」

三、打不出来时
  点「体检（打不出来）」，按输出从上往下处理：
    [X] 盒子在线        -> 盒子不在这个 Wi-Fi，重新配网或把电脑切过去
    [X] 队列端口指向盒子 -> 点「仅同步打印机端口」
    [X] 9100 可达       -> 盒子没开机 / USB 没插好 / 盒子端口没起来
    [X] 无卡死作业       -> 管理员运行「修复打印队列.ps1」

四、不用重新配网也能修端口
  盒子换了 IP（DHCP 重新分配）时，Word 里点打印没反应：
  点「仅同步打印机端口」即可，几秒钟完成。

五、自动守护（可选）
  在命令行运行：
    XiaobaiBox.exe --watch
  每 5 分钟检查一次，盒子换 IP 会自动把端口改过去。
  需要开机自启时，把这条命令做成计划任务即可。

六、数据保存在哪
  %LOCALAPPDATA%\XiaobaiBox\config.json   盒子/打印机配置
  %LOCALAPPDATA%\XiaobaiBox\wifi_history.json  Wi-Fi 记忆（DPAPI 加密，仅当前用户可解）

七、常见问题
  * 扫描不到盒子：确认盒子通电、电脑蓝牙已开、手机 App 没占用蓝牙。
  * 配网后仍找不到 IP：多半是热点开了「AP 隔离」，换手机热点或关掉隔离。
  * 提示需要管理员：改打印端口需要一次 UAC 确认，点「是」即可。
  * 端口改完 Word 没反应：把 Word 的打印对话框关掉重开一次，不用重启 Word。
