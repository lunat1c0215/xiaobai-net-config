小白盒子配网工具 · 使用说明

适用设备：XB900WB / XB94 系列小白盒子 · 版本 2.0.2

一句话：让盒子连上 Wi-Fi，并把你电脑里已经装好的那台打印机指到盒子的新地址。 不新建打印机、不装驱动；Word 里原来选哪台，修完还是哪台。

三步速查

  1. 盒子通电，打印机 USB 插在盒子上，电脑蓝牙打开。
  2. 双击 启动小白配网工具.vbs → 点「扫描盒子」→ 选中 Wi-Fi → 点「配网 + 同步打印机」。
  3. 进度条走完，回 Word 直接打印。

一、第一次使用

准备工作

  • 盒子通电，指示灯亮起；打印机用 USB 线插在盒子上并开机。
  • 电脑和盒子要连同一个 Wi-Fi。
  • 电脑蓝牙处于打开状态（没开也没关系，工具会先问你）。
  • 手机上如果装了小白 App，先退出，避免占用盒子蓝牙。

配网步骤

  1. 双击 启动小白配网工具.vbs，窗口打开后会自动识别打印机队列。
  2. 点「扫描盒子」。如果蓝牙是关的，会弹窗问你要不要自动打开，点「是」即可。
  3. 在列表里选中要连的 Wi-Fi。带 ✓ 的是以前连过、密码已记住的，会自动填好。
  4. 没记住的 Wi-Fi，手动输入密码；没有密码的网络，勾选「开放网络（无密码）」。
  5. 点「配网 + 同步打印机」，确认提示。
  6. 等进度条走完。窗口底部会显示 「Word 里请选：xxx」，记住这个名字。
  7. 回到 Word，选这台打印机，正常打印。
配网只需要一次。以后盒子换了 IP，不用重新配网，点「仅同步打印机端口」就行。

二、用手机热点时，必须切到 2.4GHz

盒子只支持 2.4GHz Wi-Fi，连不上 5GHz。 手机热点默认常常是 5GHz 或「自动」，这时配网会失败，或者盒子显示连上了但电脑找不到它。 配网前先把热点改成 2.4GHz。

安卓手机

  1. 设置 → 个人热点 / 便携式热点。
  2. 找到「AP 频段」或「热点频段」，选 2.4GHz。
  3. 如果只有「自动」，把「自动」改成 2.4GHz；没有这个选项就换一部手机或普通路由器。

iPhone

  1. 设置 → 个人热点。
  2. 打开 「最大兼容性」（Maximize Compatibility）。
  3. 开启后热点会以 2.4GHz 工作。

热点还要注意

  • 热点名称建议用英文或数字，别用中文和特殊符号。
  • 部分手机热点默认开启「AP 隔离」，盒子能上网，但电脑搜不到盒子。遇到这种情况，关掉 AP 隔离，或改用普通路由器。
  • 电脑必须连在同一个热点上，不能一边连热点一边连网线。

三、只是换了网络 / 盒子换了 IP

Word 里点打印没反应，通常是盒子被路由器重新分配了地址。

  1. 确认电脑和盒子在同一个 Wi-Fi。
  2. 打开工具，点「仅同步打印机端口」。
  3. 看到「打印机端口已指向 x.x.x.x」就好了。

不需要重新配网，也不需要重装驱动。

四、打不出来：先点「体检」

工具里的「体检（打不出来）」会直接告诉你卡在哪一步。按输出从上往下处理：

提示说明怎么处理
[X] 盒子在线盒子不在当前网络，或被断电了重新配网；或把电脑连到盒子所在的 Wi-Fi
[X] 队列端口指向盒子端口还指着旧地址点「仅同步打印机端口」
[X] 网段一致电脑和盒子不在同一个网段让两者连同一个 Wi-Fi
[X] 9100 可达盒子没把打印端口开出来检查盒子供电、打印机 USB、重启盒子
[X] 无卡死作业队列里有作业卡住了管理员运行 修复打印队列.ps1
[X] Spooler 服务Windows 打印服务没运行管理员运行 Restart-Service Spooler
体检全部通过还是不出纸，问题通常在盒子到打印机这一段：USB 线松动、打印机没开机、或盒子供电不足。

五、作业卡住 / 一直显示正在打印

  1. 关闭 Word 和其他正在打印的程序。
  2. 右键 修复打印队列.ps1 → 使用 PowerShell 运行。
  3. 弹 UAC 时点「是」，脚本会清空卡住的作业并重启打印服务。

六、常见问题

扫描不到盒子

  • 盒子是否通电？灯是否亮？
  • 盒子离电脑是否在 10 米内？中间有没有墙？
  • 手机上的小白 App 是否还开着？先退出。
  • 电脑蓝牙是否打开？工具会提示并尝试自动打开。

提示「没有蓝牙适配器」

这台电脑没有蓝牙硬件。台式机需要插一个 USB 蓝牙适配器；笔记本请检查蓝牙驱动是否正常。

配网后还是找不到盒子

  • 最常见：连的是 5GHz 热点 → 改成 2.4GHz 重配。
  • 密码输错 → 重新配一次。
  • 手机热点开了 AP 隔离 → 关掉，或换普通路由器。
  • 盒子离路由器太远 → 靠近一点再试。

端口改完了，Word 还是没反应

把 Word 的打印对话框关掉，重新打开一次即可，不用重启 Word。

弹出「用户账户控制」

改打印端口需要管理员权限，点「是」即可。点「否」会导致端口改不动。

杀毒软件报警

工具会修改打印机端口、调用 PowerShell，部分杀软会提示。选择「允许」即可。

支持哪些盒子

XB900WB、XB94 系列。其他型号如果蓝牙名字不是 XB9 开头，默认扫不到。

七、数据存在哪 / 怎么清空

内容位置
盒子与打印机配置%LOCALAPPDATA%\XiaobaiBox\config.json
Wi-Fi 记忆（加密）%LOCALAPPDATA%\XiaobaiBox\wifi_history.json
运行日志（保留最近 10 份）%LOCALAPPDATA%\XiaobaiBox\logs\
诊断包点「导出诊断包」，默认存到桌面 小白盒子诊断-时间.zip

Wi-Fi 密码用 Windows 当前账户加密，换账户或换电脑后无法解密。删除上面两个文件即可恢复初始状态。

出问题先点面板上的「导出诊断包」，把 zip 发给维护者。里面有版本、配置、体检结果、队列信息和日志，不包含 Wi-Fi 密码。

八、安装与卸载

安装：解压后双击 安装.cmd，会装到当前用户的 %LOCALAPPDATA%\Programs\XiaobaiBox，不需要管理员权限，并创建桌面和开始菜单快捷方式。也可以不安装，直接双击 启动小白配网工具.vbs 使用。

  1. 卸载：设置 → 应用 → 小白盒子配网工具 → 卸载；或运行程序目录里的 卸载.cmd。
  2. 想连 Wi-Fi 记忆一起清掉，用 卸载.cmd -PurgeData，或手动删除 %LOCALAPPDATA%\XiaobaiBox。
  3. 打印机队列和端口不需要还原，Windows 里仍是原来那台打印机。
